# Library measurements

These are the current phase-0 results from isolated, sign-in-free measurements. Version/help were captured where a supported version resolved; Codex received only `app-server` catalogue/config requests, and sign-in-free ACP agents received only `initialize` and `session/new`. Claude Code, Cursor, and Grok Build received version/help discovery only: no ACP session or model prompt was sent, and their status remains `could-not-ask`. An ACP session failure is an asked observation when initialization succeeded: `facts.signedOutCatalogue.observation=no-session`. Command updates never count as skills, so ACP catalogue reporting remains false and catalogue status remains unknown. Missing binaries, unreadable versions, and unsafe install roots are recorded separately.

The cells name their JSON facts directly. Skill-root values are observed, concrete paths relative to the agent home or fixture repository; unobserved candidates remain unmeasured. Absolute machine paths are never saved. `keychain-read-only` rows also carry the named isolation and auth fields in their JSON.
